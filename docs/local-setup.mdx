title: Local Setup
description: Install OneGlanse on your machine and run prompts on demand.
---

## Requirements

- Node.js 20 or newer
- pnpm 10 (the repository pins `pnpm@10.16.0`)
- Python 3.10+ for the local Camoufox browser (auto-provisioned where supported)
- Docker with Compose
- A desktop session for provider sign-in

If pnpm is not installed, run `corepack enable` with your Node.js installation. The repository's `packageManager` field selects its pinned pnpm version.

Native macOS, Linux, or Windows is the documented setup path. WSL requires a working graphical display such as WSLg and is not part of the supported setup path.

## 1. Clone and configure

```bash
git clone https://github.com/oneglanse/oneglanse.git
cd oneglanse
cp .env.example .env
```

Set an analysis key in `.env`. OpenAI is the default analysis provider:

```dotenv
OPENAI_API_KEY=your-key
```

To use Anthropic instead:

```dotenv
ANTHROPIC_API_KEY=your-key
ANALYSIS_LLM_PROVIDER=claude
```

See [Environment Variables](/environment-variables) for OpenAI-compatible endpoints and other settings.

## 2. Start OneGlanse

```bash
pnpm local
```

Open [http://localhost:3000](http://localhost:3000). The command installs workspace dependencies, prepares the browser files, starts Postgres, ClickHouse, and Redis through Docker, runs migrations, and starts Web and Agent from local source. The first run can take several minutes.

## 3. Connect providers and run prompts

Create an account in the app. Open Providers and complete sign-in for the providers you want to track. Then add prompts and run them from the app.

Local mode supports manual runs. For recurring schedules, see [Self-Hosted Setup](/self-hosted-setup). If startup or sign-in fails, see [Troubleshooting](/troubleshooting).
