---
title: Getting Started
description: Choose between a local installation and an always-on self-hosted deployment.
---

| | Local | Self-hosted |
|---|---|---|
| Best for | First runs, development, and testing | Always-on tracking |
| Provider sign-in | On the same machine | Capture locally, then upload sessions |
| Prompt runs | Manual | Manual and recurring |
| Deployment | Source on your machine | Docker on your VPS |

Choose [Local Setup](/local-setup) for the fastest first run. Choose [Self-Hosted Setup](/self-hosted-setup) when you need recurring schedules.

OneGlanse has no subscription or usage fee. Both modes require your own provider accounts and access to an analysis model. Self-hosting can also incur VPS and residential proxy costs.

Both paths use Docker for database services. Follow the requirements in the setup guide you choose. See [Environment Variables](/environment-variables) for configuration details.
