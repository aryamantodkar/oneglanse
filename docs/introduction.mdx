OneGlanse runs your prompts on ChatGPT, Perplexity, Gemini, Claude, and Google AI Overview and saves the answers and citations it sees.

It opens the real websites instead of calling their model APIs. That matters because the websites can add search, citations, and other behavior that a raw API call may not reproduce.

The analysis model you connect reads each saved answer and produces the visibility, rank, sentiment, and recommendation scores shown in the dashboard. You need an analysis model API key to run OneGlanse.

## What happens to your data

Prompts, answers, and scores stay in your local or self-hosted OneGlanse installation. Analysis sends saved answer text to the model endpoint you configure. The Web app also sends limited usage events to PostHog. See the [security policy](https://github.com/oneglanse/oneglanse/blob/main/SECURITY.md) for details about session transfer and data flow.

One answer does not represent every user. Results can change with the prompt, account, location, and time. Read [how OneGlanse gets its data](https://oneglanse.com/methodology) for the collection method and its limits.

To choose how to run it, see [Getting Started](/getting-started).
